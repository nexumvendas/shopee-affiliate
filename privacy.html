Política de Privacidade

Shopee Affiliate Auto Publisher

Última atualização: 14 de agosto de 2026.

1. Dados tratados

O aplicativo pode tratar URLs de produtos, informações fornecidas pelo usuário e identificadores ou tokens de autorização necessários às integrações.

2. OAuth

Quando uma plataforma oferece OAuth, a autorização ocorre pelo fluxo oficial. O aplicativo não solicita a senha da conta social.

3. Finalidade

Os dados são usados para executar as funções solicitadas pelo usuário, como conectar uma conta autorizada, preparar conteúdo e realizar operações permitidas pelas APIs.

4. Compartilhamento

Dados podem ser transmitidos a serviços de terceiros quando necessário para executar uma função solicitada e conforme as permissões concedidas.

5. Segurança

São adotadas medidas razoáveis para proteger os dados tratados.

6. Contato

Solicitações relacionadas à privacidade devem ser encaminhadas ao responsável pelo serviço.
